## Publicação
1. Extraia o ZIP do projeto.
2. Carregue os arquivos `index.html`, `style.css`, `script.js`, `configuracao.js` na raiz de seu repositório GitHub.
3. Na Vercel, importe o repositório, use Framework Preset: Other e sem build command.
4. Todas as imagens e os links de catálogo são remotos e dependem da disponibilidade dos respectivos serviços.

Para editar links ou imagens, altere `configuracao.js`. Para mudar estrutura/efeitos, altere `script.js` e `style.css`.
